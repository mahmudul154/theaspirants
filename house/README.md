# ধনশি হাউস — ডিজাইন ডসিয়ার

৩২'-০" × ১৬'-০" (৫১২ বর্গফুট) একতলা বাসভবন, ধনশি গ্রাম, নবীনগর, ব্রাহ্মণবাড়িয়া।

## কোন ফাইল খুলবেন

| ফাইল | কী | কীভাবে |
| --- | --- | --- |
| **`dhonashi-house.html`** | সম্পূর্ণ ডসিয়ার — একটি ফাইলেই সব (CSS + JS + সব SVG ড্রয়িং) | ডাবল-ক্লিক করে যেকোনো ব্রাউজারে খুলুন। ইন্টারনেট লাগবে না। WhatsApp/মেমোরি কার্ডেও পাঠানো যায়। |
| `index.html` | সোর্স ভার্সন (আলাদা `assets/` ফাইল ব্যবহার করে) | লোকাল সার্ভার দিয়ে খুলুন: `python3 -m http.server 5180` তারপর `/house/index.html` |

`dhonashi-house.html` তৈরি/আপডেট করতে (প্রজেক্ট রুট থেকে, একবার `npm install` করার পরে):

```bash
node house/build.mjs
```

## ভেতরে কী আছে

- **০১ ব্রিফ** — ক্লায়েন্টের শর্ত, জমির বাস্তবতা, মূল স্কেচের ভুল ধরিয়ে দেওয়া
- **০২ গবেষণা** — BNBC 2020 সিসমিক জোন ৩ (Z=০.২৮), বাতাস ৫৬.৭ মি/সে, বৃষ্টি ১,৯৫৬ মিমি, নবীনগর মাটির ধরন, ২০২২ বন্যা
- **০৩–০৪ প্ল্যান** — লেয়ারড ফ্লোর প্ল্যান (আসবাব / মাপ / কাঠামো / পানি / বিদ্যুৎ আলাদা করে দেখা যায়), ঘরভিত্তিক মাপ
- **০৫ ছাদ** — দুই ঢাল ২২°, ট্রাস ও পার্লিন লেআউট, শিটের হিসাব
- **০৬–০৭ এলিভেশন ও সেকশন** — চারটি দিক, দুটি সেকশন, লেভেল ডেটাম
- **০৮ ডিটেইল** — ভিত্তি, ট্রাস অ্যাংকর, ইভস-গাটার, জানালা-গ্রিল, সেপটিক, ট্যাংক প্ল্যাটফর্ম
- **০৯–১২ কাঠামো, উপকরণ, দরজা-জানালা, সার্ভিস** — লোড হিসাব, স্পেসিফিকেশন, শিডিউল, পানি-বিদ্যুৎ স্কিম্যাটিক
- **১৩ খরচ** — মূল ২,৭৪,৬৪০ টাকার বাজেট বাস্তব বাজারদরে মাপা, তিনটি পরিস্থিতি
- **১৪–১৬ কর্মসূচি, সম্প্রসারণ, রেজিস্টার** — ১৬ সপ্তাহের গ্যান্ট, ঝুঁকি তালিকা, ভবিষ্যৎ রুম, স্বাক্ষর শীট

## কৌশলগত সিদ্ধান্ত (সংক্ষেপে)

1. মাঝের বে ১০'-০" — ১২/৮/১২ ভাগে রান্নাঘর+বাথরুম ধরে না
2. সার্ভিস কোর কেন্দ্রে — সব পাইপ এক দেয়ালে
3. ছাদের ঢাল ২২° (প্রচলিত ১৫°-এর বদলে) — বৃষ্টি দ্রুত নামে, লাল-কালো রং ফুটে ওঠে
4. প্লিন্থ ২'-০" — বন্যাপ্রবণ এলাকা
5. লিন্টেল ব্যান্ড + ৮ কর্নার পোস্ট — ভূমিকম্প জোন ৩
6. পূর্ব দেয়ালে নক-আউট প্যানেল — ভবিষ্যৎ তৃতীয় ঘরের জন্য

## সীমাবদ্ধতা

এটি একটি **ডিজাইন প্রস্তাব**, নির্মাণ-অনুমোদিত ড্রয়িং নয়। নির্মাণের আগে সয়েল টেস্ট (SPT),
কাঠামো ইঞ্জিনিয়ারের স্বাক্ষর এবং স্থানীয় কর্তৃপক্ষের অনুমোদন লাগবে।

## PDF সংস্করণ

`dhonashi-house.pdf` — ৪৫ পাতা, A4 টেক্সট + A3 ল্যান্ডস্কেপ ড্রয়িং শীট।

- **A4 (৩০ পাতা)** — প্রচ্ছদ, ক্লিকযোগ্য সূচিপত্র, ১৬টি সেকশন, সব টেবিল ও ছোট ডায়াগ্রাম
- **A3 (১৫ শীট)** — ফ্লোর প্ল্যান, আসবাব প্ল্যান, ছাদ, ৪টি এলিভেশন, ২টি সেকশন, ৬টি ডিটেইল;
  প্রতিটি শীটে প্রজেক্ট নম্বর, রিভিশন ও স্কেল লেখা আছে; প্রিন্ট করলে স্কেল ঠিক থাকে
- বাংলা টেক্সট ছবি নয় — **সিলেক্ট ও সার্চ করা যায়**, ফন্ট ফাইলে এমবেড করা
- বুকমার্ক (PDF আউটলাইন) ও সূচিপত্রের লিংক কাজ করে

PDF আবার বানাতে (সোর্স বদলালে):

```bash
node house/build-svg.mjs     # ২৬টি ড্রয়িং → house/_svg/
python3 house/make-pdf.py    # → house/dhonashi-house.pdf
```

প্রয়োজন: `pip install --break-system-packages pymupdf lxml`, আর ফন্ট (`./house/fetch-fonts.sh` —
Hind Siliguri, Inter, JetBrains Mono; সবগুলো SIL Open Font License)।
